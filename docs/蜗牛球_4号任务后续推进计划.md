# 蜗牛球课题：按组员分工的后续推进计划

## 1. 当前状态与共同目标

IYPT 2027 第 3 题要求解释并研究：中空球内装有高密度小球和一定量黏性流体，沿斜面滚动时为什么表现为明显的非匀速，而且速度出乎意料地慢。

目前透明球壳、内球、黏性液体、拍摄和测量材料已经基本买齐，只差斜面。组内已经有现象与机制分析、三自由度理论模型、实验研究方案、文献整理和可运行的网页仿真器。下一阶段的核心任务是把五个人的工作接成一条完整证据链：

```text
赛题问题 → 机制假设 → 理论模型 → 实验数据 → 仿真对照 → 结论与汇报
```

当前网页仿真器中的样稿曲线使用演示参数。实物尺寸、质量、液体条件和阻尼参数尚未完成测量与标定前，样稿不能作为样球的定量预测或实验结论。

## 2. 五个人的分工与衔接

|---|---|---|---|

| 2 号 | 理论建模 | 普通球→内部重球→加入耗散的模型层级、变量和检查条件 | 1 号确定研究问题；3、4 号提供实测条件和对照需求 |
| 3 号 | 实验装置与测量 | 斜面、拍摄、四组对照、单因素实验、重复性和原始记录 | 2 号提供需测物理量；4 号提供 CSV 格式和追踪需求 |

## 3. 1 号：总体研究框架、机制分析与 PPT 整合

### 3.1 现在到斜面到位前

1. 把赛题的两个核心问题写成全组统一表述：
   - “慢”：在相同观测距离内，到达时间更长或平均速度更低。
   - “非匀速”：去除整体启动/加速趋势后，速度仍存在可重复的起伏、停顿或加速度变化。
2. 把四条机制假设整理成“现象—预测—证据”的表格：
   - 内球被带起和回落；
   - 黏性耗散；
   - 内部质量位置造成的质心/有效惯量变化；
   - 外球滑移或接触条件失效。
3. 明确哪些内容是赛题描述或待检验假设，哪些内容已经有实验或仿真证据。当前没有实测数据时，不把“可能出现周期振荡”写成已经观察到的事实。
4. 建立最终汇报的逻辑顺序：赛题现象、对照实验、理论模型、实验测量、仿真结果、模型边界和下一步验证。
5. 确定各页 PPT 需要的输入，向 2、3、4、5 号发出具体清单，避免最后临时拼接。

### 3.2 斜面到位后

1. 参加 10° 基准试拍，确认研究口径与真实现象一致。
2. 根据试拍决定优先展示哪些机制，不提前替实验下结论。
3. 统筹四组基准对照和单因素实验的编号、图表顺序和汇报用语。
4. 将 4 号输出的实验/模型对照图和 2 号的理论图放进同一条叙事线。
5. 对每个结论标明证据来源：实测、仿真、文献或待验证假设。

### 3.3 1 号交付物

## 4. 2 号：理论模型与方程检查

### 4.1 现在到斜面到位前

1. 固定坐标和符号约定：`x` 沿斜面向下为正，`phi` 为内球位置角，`psi` 为内球自转角，外球纯滚动满足 `Omega_s = -x_dot/R`。
2. 把模型分成三级，分别写清输入、自由度和用途：
   - 普通球/空壳纯滚动基准；
   - 外球加内部移动重球；
   - 加入 `k、c、gamma` 的等效耗散模型。
3. 核对三自由度状态量和方程实现：

```text
y = [x, phi, psi, x_dot, phi_dot, psi_dot]
q = (x, phi, psi)
u = b*phi_dot + r*psi_dot + (a/R)*x_dot
w = psi_dot + x_dot/R
```

4. 明确参数来源：`R、a、r、M_s、m、I_s、J` 应来自实测；`alpha` 来自斜面实测；`k、c、gamma` 是待标定的等效参数。
5. 整理数值自检清单：无耗散能量守恒、空壳极限、固定外球小振幅极限、积分收敛、内球法向力和外部纯滚动条件。
6. 给 4 号一份“理论参数表”和“方程/符号核对表”，明确哪些参数可以直接从实验输入，哪些参数需要拟合。

### 4.2 斜面到位后

1. 根据 3 号测量的几何、质量和初始状态更新模型输入，不继续使用演示值。
2. 先用无耗散和基准条件检查模型，再运行实际阻尼条件。
3. 配合 4 号决定最少需要标定的参数。若 `k、c、gamma` 无法由现有观测区分，不要同时自由拟合三个参数。
4. 根据 `d(t)`、滑移证据和液面运动判断基础模型是否仍适用。
5. 对实验数据出现的停顿、离壁、滑移等现象给出理论解释或明确标记为模型外现象。

### 4.3 2 号交付物

- 三级模型示意和变量定义。
- 与网页仿真器一致的方程、符号和参数表。
- 能量、接触、纯滚动和收敛检查记录。
- 实测参数替换说明和参数标定建议。
- 对模型失效条件的理论解释。

## 5. 3 号：斜面、实验装置与测量流程

### 5.1 现在到斜面到位前

1. 负责跟进斜面：确认制作/购买时间，并按以下条件验收：
   - 能稳定设置 5°、10°、15°，每次用倾角仪记录实测值；
   - 板面平直、支撑稳固、表面状态可以保持一致；
   - 有统一起点和无推力释放挡板；
   - 有足够宽度，球在拍摄区内不依靠侧边导轨；
   - 终点有软挡和接液托盘，观测距离 `L` 可以固定。
2. 确认相机、三脚架、标尺、照明、背景板和辅助视角是否齐全。
3. 设计并固定外壳标记、内球标记和接缝方向，保证外壳角度和内球位置可追踪。
4. 准备实验记录表，至少包含：试次编号、组别、球体尺寸、各部件质量、液体种类/体积/温度、倾角、帧率、起点、静置时间、视频名和异常情况。
5. 与 4 号确认 CSV 字段和角度单位；正式数据统一使用模板字段，角度用弧度、长度用米、时间用秒。

### 5.2 斜面到位后的试拍

1. 先用 10° 做 2—3 次基准试放，不急着进行完整参数扫描。
2. 检查球是否撞边、漏液、偏离拍摄平面或在终点前离开视野。
3. 检查外球中心、外壳标记、内球中心是否可以连续追踪。
4. 用装入同种液体后的静态位置检查曲面折射；如果折射校正残差太大，先把 `phi` 和 `d` 当作定性或低精度观测。
5. 检查释放挡板撤离是否带来初始推力，并固定视频的起止规则。

### 5.3 正式实验安排

先完成四组基准：

1. 空壳；
2. 壳加内球、无液体；
3. 壳加液体、无内球；
4. 完整蜗牛球。

再做单因素扫描，每轮只改变一项：

1. 倾角：优先 5°、10°、15°；
2. 液体黏度：低、中、高三档；
3. 填充率：根据预实验确定 20%、40%、60% 等档位；
4. 内球质量：优先使用同直径、不同密度的内球。

每个正式条件建议 5 次独立释放，穿插基准组检查漂移。停顿、滑移和未到达终点可能是结果，应保留并标记；漏液、严重撞边或追踪完全失败等预先定义的情况才列为无效试次，并记录原因。

### 5.4 3 号交付物

- 斜面和释放装置验收记录。
- 装置照片、尺寸/质量/液体条件记录。
- 四组基准和单因素实验矩阵。
- 原始视频、试次 metadata 和 Tracker CSV。
- 拍摄、折射标定、复位和重复性说明。

## 6. 4 号：仿真、Tracker 数据处理与模型对照

这是本计划中与你当前任务直接对应的部分。

### 6.1 现在到斜面到位前

1. 维护网页仿真器：确认所有可调参数、曲线、表格、CSV 导入导出和 GitHub 结果上传功能正常。
2. 固定仿真器使用的 CSV 表头：

```csv
trial_id,time_s,x_m,shell_angle_rad,phi_rad,center_distance_m,psi_rad,quality_flag
```

3. 用普通球、干燥样球或已有示例轨迹练习：CSV 导入、速度派生、曲线叠加、表格检查和异常标记。
4. 和 2 号逐项核对方程、坐标、角度符号、单位、初始条件及参数名称。
5. 建立结果目录和命名规则：

```text
results/
├─ simulations/   仿真 CSV、仿真参数 JSON
├─ experiments/   经过检查的 Tracker CSV、实验 metadata
└─ shared/        汇总表、图表和其他经过确认的材料
```

6. 准备一份数据核查表，检查时间是否递增、单位是否正确、试次编号是否重复、角度是否用弧度、球心距列是否为空以及是否存在明显跳点。

### 6.2 斜面到位后的第一轮处理

1. 根据 3 号的实测数据更新 `R、a、r、M_s、m、I_s、J、alpha` 和观测距离 `L`。
2. 先处理一段 10° 基准试拍，人工复核关键帧，再导入仿真器。
3. 输出同一条件下的实验/模型 `x(t)、v(t)、phi(t)` 叠图；如果 `psi` 可追踪，再加入 `psi(t)`。
4. 检查 `d(t)` 是否近似固定，并计算 `v - R*omega` 作为纯滚动检查量。
5. 对速度曲线使用统一的平滑或局部拟合规则，再计算速度波动；不要用单条最明显的曲线代表整组数据。
6. 记录处理参数、异常帧、折射校正版本和人工修正内容，保证别人能复查。

### 6.3 四组对照和参数扫描处理

1. 对四组基准分别计算固定距离的到达时间 `T`、平均速度 `L/T` 和重复试次离散。
2. 按实验条件绘制重复试次叠图或均值/标准差图；保留未到达、停顿、滑移和追踪失败的分类。
3. 对倾角、黏度、填充率和内球质量扫描分别建立实验表；每张表写清实际改变的变量和保持不变的变量。
4. 仿真中直接扫描 `alpha、m、r/a、k、c` 等模型参数；实验中的黏度 `eta` 和填充率 `f` 不能直接当作仿真器已有输入。
5. 先用一组条件标定少量等效阻尼参数，再固定参数预测另一倾角或工况。若参数不可辨识，应减少拟合参数或增加 `phi/psi` 等观测。

### 6.4 结果上传与归档

1. 原始视频保存在组内存储，不直接上传公开仓库。
2. 经过组内检查的实验 CSV、metadata JSON 和汇总图上传到 `results/experiments/` 或 `results/shared/`。
3. 网页生成的仿真 CSV 和参数 JSON 上传到 `results/simulations/`。
4. 每次上传文件名包含日期、条件和重复序号，例如：

```text
20261111_A10_D_full_r01.csv
20261111_A10_D_full_r01_metadata.json
```

5. 上传前确认文件不包含不应公开的个人信息、原始视频或未讨论的内部材料。仓库是公开的，提交后任何人都可能看到文件。

### 6.5 4 号交付物

- 可运行的网页仿真器和参数说明。
- Tracker CSV 模板、导入规则和数据核查表。
- 实验/模型 `x(t)、v(t)、phi(t)` 对照图和重复性统计。
- 能量、接触、纯滚动和积分收敛检查记录。
- 至少一组“用实验标定、用另一条件预测”的结果；如果暂时做不到，写明缺少哪一项数据。
- 仿真结果、实验处理结果和参数文件的 GitHub 归档。

## 7. 5 号：文献整理与证据支持

### 7.1 现在到斜面到位前

1. 至少整理 10 个有效资料，优先覆盖：

2. 每篇资料统一记录：研究对象、几何、模型、实验变量、主要结论、适用范围、与本题的相似点和差异点。
