# 蜗牛球课题：4 号任务后续推进计划

## 1. 当前状态与任务定位

赛题第 3 题要求解释并研究：中空球内装有高密度小球和黏性流体，沿斜面滚动时为什么表现为非匀速且速度出乎意料地慢。

目前实验器材材料已基本购齐，尚缺斜面。组内已有机制分析、三自由度理论模型、实验方案和文献整理。4 号任务的重点是把理论模型与实际测量数据接起来，形成可复查的仿真、视频追踪、数据处理和模型比较流程。

现有网页仿真器已支持参数调整、曲线和表格实时更新、Tracker CSV 导入，以及仿真 CSV 和参数 JSON 导出。当前样稿曲线使用的是演示参数；在实物测量和参数标定前，不能当作样球的定量预测或实验结论。仿真器也不会自动从视频识别球心，速度波动的最终分析仍需按统一规则进行平滑、误差核查和重复试次比较。

## 2. 总体工作顺序

1. 斜面未到位期间：冻结坐标约定和 CSV 字段，准备拍摄、追踪、记录模板；用普通球或干燥样球练习视频流程。
2. 斜面到位后：实测装置参数，完成相机、标尺、内球折射和释放流程的试拍验证。
3. 试拍通过后：先做四组基准对照，再逐项开展倾角、黏度、填充率和内球质量扫描。
4. 数据齐备后：按统一脚本处理轨迹，比较实验与模型；先标定少量参数，再用独立条件检验预测。
5. 完成 4 号交付：数据与处理说明、模型检查、实验对照图和汇报页。

## 3. 斜面到位前：现在就能做的工作

### 3.1 与实验装置负责人确认斜面验收条件

请负责斜面的组员给出预计完成时间，并确认以下条件：

- 支撑稳固，能重复设置实验方案中的 5°、10°、15°；每次记录倾角仪实测角度，不只记录标称值。
- 板面平直、表面状态可重复；球能在拍摄区域滚动，不需要碰侧边导轨。
- 有统一起点和不推球的释放挡板，末端有软质接球挡和接液托盘。
- 观测区间长度固定。现有仿真器默认比较距离为 0.75 m；若实际斜面可用长度不足，应选定一个所有工况都能覆盖的较短距离，并在实验和模型中统一使用。

正式斜面未到时，可以用牢固夹紧、不会晃动的临时斜面练习拍摄和追踪；临时装置的数据只用于验证流程，不并入正式结果。

### 3.2 统一坐标、角度和 CSV 字段

开始采集前，和理论组、实验组统一以下约定：

- `x`：沿斜面向下为正，单位 m。
- `theta`：外壳转角；实验追踪记录的正方向需与理论模型核对。纯滚动检验按统一符号计算 `v - R*omega`。
- `phi`：内球位置角，按理论模型定义；静止最低位置对应 `phi = alpha`。角度列使用弧度。
- `d`：外球与内球球心距，单位 m，用于检查固定球心距假设。
- `psi`：内球自转角；只有标记能稳定追踪时才填写，不可见时留空并说明。

仿真器现用的 Tracker CSV 表头为：

```csv
trial_id,time_s,x_m,shell_angle_rad,phi_rad,center_distance_m,psi_rad,quality_flag
```

实验方案写的是 `d(t)`，而现有模板使用 `center_distance_m`。为避免导入后球心距列为空，正式采集先统一使用模板字段；不要在不同文件中混用 `d_m` 和 `center_distance_m`。CSV 中角度全部用弧度，距离用米，时间用秒。

### 3.3 先练拍摄和追踪流程

在斜面完成前，用普通球或干燥样球做短片练习：

1. 固定相机和三脚架，镜头尽量垂直于运动平面；标尺放在球心所在的测量平面。
2. 试拍 120 fps；若画面太暗或标记不清，再调整照明、快门和帧率，确保运动没有明显跨帧模糊。
3. 练习追踪球心位置和外壳标记，确认像素到长度的标定可复现。
4. 对透明球壳内的静止小球做位置标定，检查曲面折射对 `phi` 和 `d` 的影响。换液体或填充状态后需复核；如果无法可靠校正，先将内球角度作为定性观测，不用于精确拟合。
5. 记录释放挡板撤离方式、起点和视频终点，确保释放过程没有手推、碰撞或侧向偏移。

## 4. 斜面到位后：首次试拍与通过标准

### 4.1 实测并建档

每个样球/工况记录：

- 球壳外半径 `R`、空腔半径 `a`、内球半径 `r`；球壳、内球和完整装置质量。
- 液体种类、批次、体积或质量、密度（可得时）、温度；有黏度数据时记明测量温度和单位。
- 填充率定义及计算值、斜面实测倾角、起点、观测距离 `L`、视频帧率和标尺标定信息。
- 初始内球位置、静置时间、外壳接缝方向、视频文件名及异常情况。

### 4.2 先做小规模试拍

先选 10° 作为基准倾角，用 2–3 次试放检查：

- 球是否能在可用观测区内完整通过，是否撞侧边、漏液或碰到接球挡。
- 外壳标记是否可连续追踪；内球是否可见，折射校正残差是否可接受。
- 视频是否覆盖从释放到终点；挡板释放是否产生可见初速度。
- 同条件试次曲线是否大致可重复，数据表能否导入仿真器并正确叠加。

若相机、折射、释放或追踪有问题，先修流程再开始参数扫描。试拍可以用来调设备，但不要把挑选过的单条曲线当作正式结果。

## 5. 正式实验采集建议

### 5.1 四组基准对照

在相同球壳或匹配球壳、倾角、斜面表面、起点和释放方式下，完成：

1. 空壳；
2. 壳加内球、无液体；
3. 壳加液体、无内球；
4. 完整蜗牛球。

每组称量总质量并记录几何、液体体积和温度。不同组的总质量与质量分布不同，组间速度差只能先作为机制线索，不能直接等同于黏性耗散差异。

### 5.2 单因素扫描顺序

正式扫描每次只改变一个变量，其他条件保持不变。建议先完成基准对照，再按组内时间优先安排：

1. 倾角：5°、10°、15°，检查运动趋势和是否滑移。
2. 黏度：低、中、高三档，固定填充率、内球和温度条件。
3. 填充率：例如 20%、40%、60%，固定液体种类和内球。
4. 内球质量：优先使用同直径、不同密度的内球，避免同时改变直径、间隙和可用液体体积。

这些档位是实验方案中的起始建议，需要根据试拍调整。每个条件最终建议进行 5 次独立释放，随机化不同条件的测量顺序，并穿插基准组检查漂移。试拍阶段可先少量重复，确认流程稳定后再补足正式重复数。

停顿、滑移或未到达终点可能是研究现象，应保留并单独标记。只有漏液、严重撞边或无法恢复的追踪失败等预先定义的情况才列为无效试次，并记录原因；不要为了曲线整齐而删除数据。

## 6. 数据处理与仿真对照

### 6.1 统一视频数据处理

每段视频同步提取外球中心 `x(t)`、外壳角 `theta(t)`、内球位置角 `phi(t)` 和球心距 `d(t)`；`psi(t)` 仅在标记稳定可见时提取。人工复核若干关键帧，保存原始视频、原始追踪 CSV、校正版本和处理参数。

位置曲线采用同一平滑或局部拟合规则后再计算速度。重点输出：

- 固定观测距离 `L` 的到达时间 `T` 和平均速度 `L/T`；若没有稳定速度段，不把平均速度称为末速。
- 去除整体启动/加速趋势后的速度波动强度，例如 `delta_v = v - v_trend` 的均方根；检查更换合理平滑窗口后结论是否仍成立。
- `v - R*omega` 与测量误差，用于检查纯滚动；接近静止时不要用 `v/(R*omega)` 比值。
- `phi(t)` 与 `v(t)` 的同步变化；只有多个周期在重复试次中稳定出现，才讨论周期和相位。
- `d(t)` 是否近似固定、液面是否显著运动，以及内球是否有离壁迹象。

### 6.2 与现有仿真器衔接

当前仿真器可导入 Tracker CSV，显示实验与模型曲线；网页计算的模拟结果和演示扫描可作为工作流检查。建议使用它做快速叠图和参数探索，最终速度曲线、去趋势指标和误差分析由统一的数据处理脚本复核。

基础模型将液体作用简化为等效耗散，参数 `k、c、gamma` 不是黏度 `eta` 或填充率 `f` 的直接替代。实验改变黏度或填充率时，先报告实测曲线与统计量；不要把实验黏度值直接填入 `k`。可用一组条件标定必要的最少阻尼参数，再固定参数预测另一倾角或工况。若同一条外球轨迹无法区分多个阻尼参数，不要同时任意拟合它们。

用实测 `R、a、r、M_s、m、I_s、J` 代替演示值，并核对模型适用条件。若 `d(t)` 明显变化、内球离壁、外球滑移显著或液面运动强，应标出基础模型失效区间，而不是只通过调参消除偏差。液体质量、浮力和自由液面影响也应有记录后再判断能否忽略。

### 6.3 上传与资料管理

原始视频先保存在组内存储，不上传到公开仓库。经过检查的 CSV、参数 JSON 和汇总图可放到 GitHub 仓库的 `results/experiments/` 或 `results/shared/`，按试次编号命名；仿真器直接上传的模型 CSV 和参数 JSON 位于 `results/simulations/`。仓库是公开的，上传内容任何人可见。每次上传同时保存能还原工况的参数和 `trial_id`，不要只上传图片或单条“最好看”的曲线。

建议文件名包含日期、条件和重复序号，例如：

```text
20261111_A10_D_full_r01.csv
20261111_A10_D_full_r01_metadata.json
```

具体命名可由组内统一；同一个 `trial_id` 必须能对应原始视频、追踪 CSV 和实验记录表。

## 7. 4 号任务阶段性交付

- 一份冻结版 CSV 字段、坐标符号、单位和命名规范。
- 一套可重复的视频追踪与 CSV 处理流程，包含标尺/折射校正记录、平滑方法和误差说明。
- 四组基准及优先参数扫描的 `x(t)、v(t)、phi(t)` 叠图和重复试次离散统计。
- 现有模型的参数来源、能量/接触/纯滚动检查和适用范围说明。
- 至少一个“用一组实验标定、用另一条件验证”的模型比较；如数据暂不支持，要明确报告原因和下一步测量需求。
- 汇报建议 1–2 页：一页说明数据采集、处理和误差；一页展示代表性实验与模型对照，并区分实测值和演示仿真值。
