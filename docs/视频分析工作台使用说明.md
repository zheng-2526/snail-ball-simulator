# 蜗牛球本地视频分析工作台

## 打开方式

双击仓库里的 `index.html`，选择顶部“视频分析”。该入口的全部分析代码已经内嵌，单独复制 `index.html` 仍可使用；不需要 Python、服务器、联网或安装依赖。也可单独打开 `video-analysis.html`。

视频只由当前浏览器读取，不会自动发送到服务器。仿真器中已有的 GitHub 上传仍由用户主动操作；分析工作台自身不包含任何联网请求。

## 首次试用

点击“试用合成演示”，然后点击“开始自动分析”。这个例子已设置标尺、方向和目标，可先熟悉结果图、逐帧复核和发送到仿真器的流程。演示明确标记为合成数据，不能当作实验。

## 自己的视频如何操作

1. **选择本地视频。**浏览器会读取分辨率和时长；常规 MP4/MOV 还会尝试读取编码平均帧率、编码帧数和可变帧率信息。其他格式能否打开取决于浏览器解码支持，优先使用 MP4/H.264。不能解码时须先在本机转码，原文件保留。
2. **核对真实时间。**正常时间轴的录像填慢动作倍率 1。若采集 120 fps、所有帧按 30 fps 保存，填 4。真实时间等于视频时间除以倍率；文件帧率不能自行证明真实拍摄倍率。核对后勾选确认框，否则不能导出定量 CSV 或发送。
3. **选择片段。**用时间轴定位释放附近一帧，点“当前帧设为起点”，填写终点。分析采样率指每视频秒分析多少帧，不是拍摄倍率；单轮最多 4000 帧，可缩短片段或降低采样率。采样率须足以分辨最快的标记运动和速度起伏；低采样率可能漏掉或混叠真实波动。
4. **标尺标定。**填入画面中标尺两点的真实距离（m），点“点标尺两端”，依次点两端。标尺须与球的运动平面尽量一致。
5. **设方向。**点“点下坡方向两点”，依次点上坡位置和下坡位置。法向箭头应指向斜面外侧，不正确时勾选翻转。
6. **选择追踪目标。**必须在片段起点点选外球中心和边缘。内球也按中心→边缘选择；外壳标记、内球自转标记各点一次；清晰、颜色独特的标记优先使用颜色区域追踪，灰度标记使用模板匹配。外壳标记用于外球角速度与滑移残差；不能用内球公转位置角代替内球自转角。
7. **填写试次条件。**倾角、实测半径、质量、液体条件与温度可填；未知值留空。没有实测外半径时，纯滚动残差使用标尺和画面半径估计的 R，须注意相应误差。
8. **开始自动分析。**软件逐帧解码、搜索轮廓/模板，自动输出位置、角度、局部拟合速度和指标。画面反光、标记遮挡、透明球边界模糊时仍需复核。

## 如何修正和继续

默认在外球或内球低于追踪分数阈值时暂停。分数是匹配指标，不是正确率，仍应抽查高分帧。

- 点击“下一个疑问帧”，或输入数据行并跳到该帧。
- 选择左侧对应目标按钮，在原画面上重新点选；球心目标仍需点中心和边缘。
- 对不可见目标，选择“此帧目标不可见”，保留缺失，避免凭空推测。
- 点击“从所选帧继续”，软件以该帧的已确认位置重建模板，替换之后的追踪结果。重新运行前建议先保存工程。
- 外壳标记或内球标记进入背面时会留空，不会把推测位置当实测值。若从没有标记的帧恢复，该轮不继续追踪该缺失标记，须在标记重新可见的帧手动设置后恢复。

## 自动得到什么

- 外球沿斜面位移、原始位置与平滑位置、速度。
- 外壳各连续可见片段内的展开转角和角速度，约定下坡滚动为正（遮挡后累计圈数未知，另有片段重启标记）；纯滚动残差为 `v - R*omega`。
- 内球投影位置角和投影球心距；内球标记可见时保存投影自转角。
- 固定观测距离的到达时间、平均速度、初步线性去趋势速度 RMS；未到达不使用更短路段替代。
- 对所选平滑窗口以及相邻两个窗口计算的指标，保存在 metadata 中，便于检查处理窗口敏感性。
- 每帧匹配分数、缺失/人工修正标记和时间戳质量。

平滑速度使用按真实时间拟合的局部二次多项式。缺失帧和明显时间间隙不会自动插值；可用样本少于 3 个的片段不给出导数。端点导数标记为 `derivative_edge`。有很多窗口选择不代表有很多独立实验，重复性仍需重新释放球进行独立录像。

## 内球折射与出平面运动

程序不能从一段普通录像自动恢复真实三维位置、球壳折射或液体折射率。默认只输出 `phi_projected_rad`、`d_projected_m`，定量列 `phi_rad`、`center_distance_m` 留空。仿真器可把投影角以明确标记的虚线叠加，不应据此做精确参数拟合或断定离壁。

若已经针对当前液体、视角和位置范围做过独立静态标定，可以填写下坡/法向相对位移的线性校正倍数并确认。线性映射只适用于其已验证的范围，不是通用光学修正。当前标记自转角仍属二维影像测量；复杂球面标记转动或出平面运动不能由一个点唯一恢复。

## 一键发送到仿真器

在 `index.html` 的“视频分析”界面点击“一键发送到仿真器比较”，页面会切到交互仿真、显示实验数据表并叠加曲线。处理后的速度会被保留，不再被简单差分覆盖。缺失数据在曲线上断开。

若勾选“带入已填写的实测条件”，填写过的倾角、半径和质量会带入；未知阻尼、初态和惯量仍需核对。程序不会根据球半径推断液体黏度、内部重球质量或阻尼。内球投影角会明确标为未校正投影。合成演示会始终标为非实测。

独立入口会尝试打开同目录的 `index.html` 再发送；若浏览器阻止弹窗或文件不在同目录，可导出 CSV 后在仿真器中手动导入。

## 导出文件

| 文件 | 内容与用途 |
| --- | --- |
| `*_processed.csv` | 仿真器兼容 CSV；包含平滑速度、原始位移、投影角、质量标记与速度来源 |
| `*_raw_tracking.csv` | 原视频分辨率下的已接受球心/标记二维坐标及分数，方便复查 |
| `*_metadata.json` | 视频信息、实测条件、时空标定、处理设置、窗口敏感性和统计量 |
| `*_analysis_project.json` | 完整标定和逐帧追踪/修正工程，不含视频内容；恢复时重新选择原视频 |

原始点位和低分候选也保存在工程文件中。恢复工程会核对原视频的名称、大小和尺寸；这些检查不替代原文件备份。保存工程不等于保存视频。

## 当前能力边界

这是基于视频轮廓与模板的本地辅助追踪工具。它能减少重复点选和计算工作，但不能保证任意光照、任意透明壳、遮挡或三维运动下全自动正确。无法自动得到的几何、液体性质、真实时间倍率和折射标定必须实测/确认。

目前已用已知运动的合成数据和生成的视频检查数值处理、元数据读取、追踪、CSV 与仿真桥接。小组自己的第一段实拍视频仍应逐帧抽查后再进行批量分析。视频中的摄像机抖动、透视变化和强烈畸变应先在采集端控制，软件不自动把这些当成物体运动修正。

## 维护与验证

维护源文件位于 `assets/video-analysis-core.js`、`assets/video-analysis-ui.js`、`assets/simulator-video-bridge.js` 和 `src/video-analysis.template.html`。修改后运行 `python tools/build_video_analysis.py`，会生成独立页面并重新内嵌到主仿真器。

可用 Node 自带测试运行 `node --test tests/video-analysis.test.cjs`。这些源代码和开发工具不是日常运行依赖。
