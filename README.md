# 蜗牛球仿真器

一个可离线运行的蜗牛球简化动力学仿真网页。项目只有一个自包含的 `index.html`，不需要安装依赖，也可以部署到 GitHub Pages。

## 功能

- **整体仿真样稿**：展示基准运动、等效耗散参数扫描和数值自检图表。
- **交互仿真工作台**：调整球体参数、倾角、初态和积分设置，自动更新曲线、摘要和结果表。
- **参数扫描**：扫描倾角、质量、几何尺寸或等效耗散参数。
- **实验数据对照**：导入 Tracker CSV，叠加实验与模型曲线；模板见 `tracker_data_template.csv`。
- **数据导入导出**：支持参数 JSON、仿真 CSV、扫描 CSV 和处理后的实验 CSV。

## 本机运行

下载或克隆项目后，任选一种方式：

1. 双击 `index.html`，默认浏览器会打开页面。
2. Windows 用户也可以双击 `run_local.bat`。

程序在浏览器本地运行。导入的实验数据和计算结果不会由本页面发送到服务器。浏览器会在当前站点保存参数；更换设备或浏览器时，可通过参数 JSON 导入导出迁移设置。

## 发布到 GitHub

### 用 GitHub 网页上传

1. 在 GitHub 新建一个仓库。
2. 将本项目文件夹中的文件上传到仓库根目录并提交。
3. 如果希望通过网页访问，在仓库的 **Settings → Pages** 中选择从 `main` 分支的根目录发布。
4. 等待 Pages 部署完成后，使用 GitHub 提供的网址打开 `index.html`。

### 用 Git 命令上传

先在 GitHub 新建空仓库，然后在本项目文件夹打开终端运行：

```bash
git init
git add .
git commit -m "Add snail ball simulator"
git branch -M main
git remote add origin https://github.com/你的用户名/你的仓库名.git
git push -u origin main
```

仓库地址中的用户名和仓库名替换成你刚创建的地址。之后可按上面的 Pages 步骤发布网页。

## 项目文件

- `index.html`：完整网页，样稿图表也已内嵌；不依赖其他资源文件。
- `tracker_data_template.csv`：Tracker 数据格式模板。
- `run_local.bat`：Windows 本地启动快捷方式。

## 模型范围

本程序采用组内研究的三自由度简化模型。当前演示参数不是实物测量值；`k、c、γ` 是等效耗散参数，尚未标定到具体液体黏度或填充率。模型忽略液体质量、浮力、自由液面运动及外球滑移。仿真结果用于研究和教学讨论，不应直接当作实验结论。
