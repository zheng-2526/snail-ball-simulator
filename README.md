# 蜗牛球仿真器

> 📋 **[查看 4 号任务后续推进计划](docs/蜗牛球_4号任务后续推进计划.md)**：包括斜面到位前准备、试拍、正式采集、数据处理和交付清单。

> 🎬 **[新手使用方法](#使用方法)** · **[完整视频分析说明](docs/视频分析工作台使用说明.md)**

一个可离线运行的蜗牛球简化动力学仿真网页。项目只有一个自包含的 `index.html`，不需要安装依赖。

## 功能

- **整体仿真样稿**：展示基准运动、等效耗散参数扫描和数值自检图表。
- **交互仿真工作台**：调整球体参数、倾角、初态和积分设置，自动更新曲线、摘要和结果表。
- **参数扫描**：扫描倾角、质量、几何尺寸或等效耗散参数。
- **实验数据对照**：导入 Tracker CSV，叠加实验与模型曲线；模板见 `tracker_data_template.csv`。
- **本地视频分析**：读取本地视频，标定尺度/方向后辅助追踪球心和标记，计算平滑速度、角度及纯滚动残差；低分帧可复核修正，结果一键送入仿真器。详见 [视频分析使用说明](docs/视频分析工作台使用说明.md)。
- **数据导入导出**：支持参数 JSON、仿真 CSV、扫描 CSV 和处理后的实验 CSV。
- **GitHub 结果直传**：在工作台将仿真 CSV 和参数 JSON 上传到 `results/simulations/`，也可选择其他文件上传到自定义目录。需联网、仓库写权限和到期时间受限的经典 PAT（`public_repo`）；令牌不会保存，上传后清空。仓库公开，上传文件可被任何人查看。

## 本机运行

下载或克隆项目后，任选一种方式：

1. 双击 `index.html`，默认浏览器会打开页面。
2. Windows 用户也可以双击 `run_local.bat`。

程序默认在浏览器本地运行，参数保存在当前站点。只有用户主动使用 GitHub 直传时，所选仿真结果或文件才会发送到目标仓库；更换设备或浏览器时，可通过参数 JSON 导入导出迁移设置。

## 使用方法

### 第一次使用：先跑一遍演示

1. 从本仓库下载 ZIP 并解压，双击 `index.html`。GitHub 上的 HTML 代码预览页不会直接运行程序。
2. 点击顶部 **“视频分析”**，再点击 **“试用合成演示”**。
3. 点击 **“开始自动分析”**。演示已经设置好时间、标尺、方向和目标，可以直接查看位移、速度、内球投影角和纯滚动残差。
4. 点击 **“一键发送到仿真器比较”**。页面切换到交互仿真，显示实验数据表和模型叠加曲线；演示始终标记为合成数据，不是实测结果。

日常使用不需要安装 Python、Tracker 或开发工具。`index.html` 已内嵌三个界面，单独复制到其他电脑也能打开；完整文件夹还包含独立入口、模板和说明。

### 分析自己的实验视频

按下面顺序操作，可避免中途改变片段起点后需要重新选目标：

1. **选择视频。**进入“视频分析”，点击“选择本地视频”。软件自动读取分辨率、时长，并尝试读取 MP4/MOV 的编码平均帧率。优先使用浏览器可解码的 MP4/H.264。
2. **确认时间尺度。**正常时间轴的录像将“慢动作倍率”填为 `1`。如果拍摄 120 fps、保留全部帧并按 30 fps 保存，才填 `4`，因为实际时间 = 视频时间 ÷ 倍率。核对后勾选“我已核对真实时间尺度”。编码帧率本身不能证明慢动作倍率。
3. **确定片段。**用时间轴找到释放附近的起始帧，点击“当前帧设为起点”，再填写终点。分析采样率须足以分辨运动；单轮最多 4000 个采样帧。
4. **设置标尺。**填入画面中标尺两点的真实距离，单位是米。例如 20 cm 填 `0.2`。点击“点标尺两端”，依次点击两端。
5. **设置方向。**点击“点下坡方向两点”，依次点击上坡点和下坡点。检查法向箭头是否朝向斜面外侧；反了就勾选“翻转法向”。
6. **选择目标。**在片段起点，点击“外球：中心→边缘”，再依次点外球中心和轮廓边缘。内球同样操作；外壳标记和内球标记各点一次。外球是必选目标；不清晰的可选目标可以不设置。清晰且颜色独特的标记更容易追踪。
7. **填写条件。**输入试次编号、实测倾角、半径、质量、液体条件和温度。未知项留空，不要把演示值当作实测值。
8. **开始分析。**点击“开始自动分析”，等待自动读帧、追踪和计算。先检查一段短片，确认追踪可靠，再分析完整视频。

### 追踪暂停或点位不正确时

- 点击“下一个疑问帧”，或输入数据行并点击“跳到此帧”。
- 使用画面上方的“修正外球”“修正内球”等按钮重新点选。球心目标需要点中心和边缘两次。
- 如果目标确实不可见，选中相应目标并点击“此帧目标不可见”，保留缺失记录。
- 修正后点击“从所选帧继续”。软件会保留之前的结果，重新追踪之后的片段；建议先保存分析工程。

追踪分数是匹配指标，不是正确率，高分帧也需要抽查。遮挡后的累计圈数不能凭空确定；软件不会用推测位置填满缺失帧。

### 发送到仿真器并保存结果

点击 **“一键发送到仿真器比较”**，处理后的数据会直接送到同一网页的交互仿真界面，保留平滑速度并叠加曲线。勾选“发送时将已填写的实测条件带入仿真器”后，填写过的倾角、半径和质量会一起带入；阻尼、惯量、初态及剩余参数仍需核对。

| 保存按钮 | 保存什么 | 何时使用 |
| --- | --- | --- |
| 导出仿真器 CSV | 平滑轨迹、速度、角度和质量标记 | 分享数据，或在另一份仿真器中手动导入 |
| 导出原始追踪坐标 CSV | 原视频分辨率下的球心与标记点坐标、匹配分数 | 复核和重新处理 |
| 导出 metadata JSON | 视频信息、标定、实测条件、处理设置和指标 | 记录结果如何得到，随 CSV 一起保存 |
| 保存分析工程 | 标定、逐帧点位和人工修正记录 | 下次继续工作；恢复前先选择同一原视频 |

**分析工程不包含原视频，请同时保留原视频。**恢复工程不会替你备份视频。若单独打开 `video-analysis.html`，发送时会尝试打开同目录的 `index.html`；弹窗被拦截时可导出 CSV，再在仿真器中点击“导入 Tracker CSV”。

默认的内球角和球心距是未折射校正的投影值，仿真器会明确标记；不能仅凭它们精确拟合或断言内球离壁。只有完成了当前液体、视角和位置范围的独立标定，才使用相应校正设置。更详细的测量约定、处理方法和限制见 [完整视频分析说明](docs/视频分析工作台使用说明.md)。

### 常见问题

| 问题 | 处理办法 |
| --- | --- |
| 视频无法打开 | 换用支持该视频编码的浏览器，或在本机将副本转成 MP4/H.264；保留原文件 |
| 不能导出或发送 | 检查是否已确认时间尺度、完成标定且至少有 3 个有效位置点；修改片段或采样设置后需重新分析 |
| 速度量级明显不对 | 先检查标尺是否把 cm 当成 m，以及慢动作倍率是否填写正确 |
| 经常暂停或追错目标 | 改善照明与标记对比度，缩短测试片段，适当提高采样率；跳动较大时调整搜索半径并人工复核 |
| 内球定量角度或球心距为空 | 未确认独立标定时会保留为空，同时输出明确标记的投影值 |
| 发送后模型报参数错误 | 核对半径关系 `R > a > r`、质量、初态和惯量；只填写部分实测参数时，其余默认值可能不再适用 |

## 项目文件

- `index.html`：完整网页，包含样稿、交互仿真和视频分析三个界面，全部代码内嵌。
- `video-analysis.html`：视频分析独立入口，可单独离线打开。
- `assets/`、`src/`、`tools/`：维护用源代码及生成脚本，正常使用不需要安装或构建。
- `tracker_data_template.csv`：Tracker 数据格式模板。
- `run_local.bat`：Windows 本地启动快捷方式。

## 模型范围

本程序采用组内研究的三自由度简化模型。当前演示参数不是实物测量值；`k、c、γ` 是等效耗散参数，尚未标定到具体液体黏度或填充率。模型忽略液体质量、浮力、自由液面运动及外球滑移。仿真结果用于研究和教学讨论，不应直接当作实验结论。
